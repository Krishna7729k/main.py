# Project Statement

## Project Title

File Organizer

## Problem Statement

Managing a folder containing different types of files can be difficult and time-consuming. This project automatically organizes files according to their file extensions.

## Scope

The project takes a folder path as input, identifies file extensions, creates folders for different extensions, and moves files into their respective folders.

## Target Users

- Students
- Computer users
- Anyone who wants to organize files easily

## High-Level Features

- Accept folder path as input
- Identify file extensions
- Create extension-based folders
- Move files into respective folders
- Automatically organize files

## Technologies Used

- Python
- OS Module
- Shutil Module
